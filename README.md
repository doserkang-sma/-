# 組織學 Vol.8 皮表系統（Integumentary System）複習測驗系統

專為醫學生設計的組織學期中與跑台快速複習網頁測驗系統，依據組織學共筆 Vol.8 精準命題。

## 🌟 系統特色
- **50 題完整題庫，每次隨機抽樣 20 題**：涵蓋表皮分層、表皮細胞、真皮與附屬器官、皮膚腺體、毛髮指甲、感覺受器、實驗跑台切片及臨床病理等 7 大核心單元。
- **純淨高解析度顯微切片圖譜**：實驗跑台題目直入組織切片原圖（Slide A-25、A-26、A-63、B-25、B-26、B-27、C-22 等），無共筆贅字與大片留白，題卡即時清晰呈現。
- **平衡無提示選項設計**：各選項長度與格式均一，杜絕格式洩題。
- **雙測驗模式**：
  - **即時回饋模式**：點選選項立刻判斷對錯並展開共筆原頁詳解。
  - **模擬考試模式**：考完後統一交卷結算，提供診斷報告與錯題回顧。
- **多功能學習工具**：錯題標記收藏、快速篩選單元、成績結算與雷達式弱點分析。
- **純靜態架構**：零外部相依性，完全支援 GitHub Pages 部署，手機瀏覽器即開即測。

## 🚀 部署至 GitHub Pages
1. 將本專案檔案推送至 GitHub 儲存庫。
2. 進入儲存庫的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下方的 **Source** 選擇 `Deploy from a branch`。
4. **Branch** 選擇 `main`（或 `master`），資料夾選擇 `/ (root)`，點擊 **Save**。
5. 數十秒後即可獲得專屬網址（例如：`https://<your-username>.github.io/<repo-name>/`），搭車或隨時隨地用手機開啟複習！
